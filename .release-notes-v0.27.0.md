## Releases are macOS-only

- Release builds now produce a single darwin-arm64 tarball. Linux tarballs are no longer built, and the Homebrew formula no longer has a Linux section. vellum's clipboard, Finder file references and viewer are darwin-only, so this matches what the product supports. Existing v0.26.x Linux assets are left in place.

## One definition of green

- `make bullseye` now delegates to `cv bullseye`, so it runs the same gate as `cv gate` (VELLUM_REQUIRE_DEPS=1, -race, skip census, CLI contract) instead of a weaker separate recipe.
