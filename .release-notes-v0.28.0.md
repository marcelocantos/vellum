## Windows support

vellum now runs on Windows (arm64 and amd64) as well as macOS.

- **Core:** CLI and MCP `convert` (Markdown → HTML, PDF, pptx), rich-text and PDF import, and the localhost viewer all work on Windows. Config and templates live in `%APPDATA%\vellum` (`XDG_CONFIG_HOME` still wins). Paths with drive letters work in view URLs and `file://` links, and mmdc's npm `.cmd` shim is run through node directly.
- **Clipboard:** a pure-Go Windows backend writes CF_HTML, RTF (via pandoc) and Unicode text in one transaction, reads RTF, HTML and PDF, and reads and writes CF_HDROP file lists for `file_reference`.
- **Background viewer:** `vellum install-service` registers a per-user logon Scheduled Task that runs `serve-view` in your desktop session (no admin, no console window, no time limit); `vellum uninstall-service` removes it. "Show in Finder" reads "Show in Explorer" on Windows, and help text is per-OS.
- **Install:** release assets now include `vellum-<version>-windows-arm64.zip` and `-windows-amd64.zip` plus `checksums-<version>.txt`. The repo doubles as a scoop bucket: `scoop bucket add vellum https://github.com/marcelocantos/vellum`, then `scoop install vellum/vellum`. The Homebrew formula stays macOS-only, and there are still no Linux builds.
- KaTeX is found in the global npm modules on Windows too, so `NODE_PATH` is not needed.

Not on Windows: `install-viewer` (default `.md` handler). The Windows suite runs with `VELLUM_REQUIRE_DEPS=1` and 0 skips on a Windows 11 arm64 VM.
