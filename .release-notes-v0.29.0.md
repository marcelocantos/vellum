## Windows bookkeeping

No code changes. This release records what v0.28.0 already shipped and how Windows is checked.

- **Windows is a supported platform.** STABILITY no longer says Windows is untested or that clipboard `Write` is macOS-only. On Windows the clipboard writes HTML, RTF and plain text in one transaction, reads RTF, HTML and PDF, and handles file references. `--to-clipboard`, `import --from-clipboard` and the `clipboard` / `file_reference` media work on macOS and Windows; Linux stays unsupported.
- **How Windows is checked.** Green means `cv gate` on macOS plus the full suite with `VELLUM_REQUIRE_DEPS=1` and 0 skips on a Windows 11 arm64 VM. There is no GitHub Actions job and no Linux build.
- **Still to check:** pasting into Microsoft Word and Outlook on Windows. A paste into the RichEdit control (the engine behind WordPad) keeps headings, bold, italic, code, links, lists, quotes and tables.
- Rich text on the macOS clipboard (AppKit first, pandoc fallback) is recorded as done.
