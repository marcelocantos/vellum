### Changed

- **Every SVG that stands alone grows to reading size in the viewer**, as Mermaid diagrams and plain SVG images already did. This now covers a document's own `<svg>` (on its own lines or alone in a paragraph), an SVG image inside a link, inside raw HTML `<figure>` (the caption stays below), `<picture>` or `<div align="center">`, and `data:image/svg+xml` images. A remote SVG image is measured after the page loads, so the page never waits on it; the result is remembered and written into later pages. An image the viewer cannot fetch itself, such as one behind a sign-in, keeps its size. The viewer fetches only images the open document shows.
- A standalone inline drawing now sits at the left of the column like an image (centred once wider than the column), rather than against the right edge.

### Notes

- Left as written: an SVG inside a sentence, drawings side by side, an SVG its author sized (width or height attributes, a style width, a percentage width) and an SVG without a `viewBox`.
- The development viewer's LaunchAgent now signs the checkout's build so macOS keeps its privacy grants across rebuilds. This affects only development checkouts, not the Homebrew install.
