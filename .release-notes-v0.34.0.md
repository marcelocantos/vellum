## PDF layout

- **Wide tables no longer lose trailing columns in the PDF.** Print CSS now
  fits tables to the page (`width: 100%`, `table-layout: fixed`, wrapping
  cells) instead of GitHub's scroll-friendly `max-content` + `overflow: auto`,
  which WeasyPrint and Prince clipped at the right margin.
- **Oversized images and Mermaid diagrams scale down to the printable
  width** (`max-width: 100%`, `height: auto`) so they are not cropped.

## Viewer download menu

- The toolbar **PDF⤓** control is now a **download icon** with a popup
  menu: **PDF** (same download as before) and **Source**.
- **Source** opens a new tab that renders the Markdown source inline
  (monospace, escaped), like browser view-source, via `GET /_vellum/source`.
