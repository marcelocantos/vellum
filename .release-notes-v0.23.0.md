## Changed

- The view server watches each open document with the system file watcher. One watcher is shared by every tab on that path.
- An edit reloads the tab after the file has been quiet for a moment, so a partial write is not loaded.
- Renaming the file redirects the open tab to the new path.
- Deleting the file leaves the rendered page in place and reports the deletion.
- A missing file stays on a waiting page and opens when the file appears.
