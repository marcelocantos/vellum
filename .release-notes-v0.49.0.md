### Fixed

- **Cloud-only files open under the service.** Documents in OneDrive, Google Drive, iCloud Drive and other macOS cloud folders that were not downloaded failed to open in the viewer started by `brew services` with "resource deadlock avoided". launchd does not let a service download such files. vellum now allows it for its own process at startup, so the file downloads when it is read; pandoc, WeasyPrint and Mermaid run by vellum inherit this. The `MaterializeDatalessFiles` plist key is no longer needed, and a `brew upgrade` that rewrites the plist no longer brings the failure back.
