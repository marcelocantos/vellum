### Added

- The viewer has a source editor. The pencil button (or `e`) opens a modal CodeMirror 6 editor on the Markdown source, with GFM syntax highlighting and highlighted fenced code. `Cmd/Ctrl-S` saves and Escape closes. The editor is embedded in the binary and loads nothing from the network.
- The editor opens at the part of the document the page was showing, and closing it returns the page to what the editor showed. If the editor was not scrolled, the page returns exactly where it was.
- Text selected on the page arrives selected in the editor's source.
- Saving checks that the file has not changed on disk since the editor loaded it. If it has, the editor says so and offers to overwrite, reload from disk, or keep editing, instead of silently replacing the other change.

### Changed

- The toolbar uses icons: a PDF page, a pencil for edit, a copy icon, and the system file manager's own icon for reveal (Finder on macOS).
- The download menu is now a single PDF button.

### Removed

- The Source view and its `/_vellum/source` endpoint. Use the editor to read or select the raw Markdown.
