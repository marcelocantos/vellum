## Added

- Viewer live reload: an open tab watches the source over WebSocket (`/_vellum/watch`), reloads when mtime/size changes, and restores scroll by heading (5-minute protocol heartbeat).
- Editable GFM task-list checkboxes in the viewer: first click asks for consent (this session or always), then `POST /_vellum/task-toggle` flips the matching `- [ ]` / `- [x]` in the Markdown file.

## Changed

- Task-edit consent is a modal dialog, not a toolbar strip, so the first click is not mistaken for a no-op.
