## Changed

- Math documents no longer fetch KaTeX's stylesheet from jsDelivr. The stylesheet and its woff2 fonts ship inside vellum (`embed/katex`, KaTeX 0.16.45, the same package the renderer loads), so math renders offline, air-gapped, or with the CDN blocked, and no third party can supply CSS into a PDF. The view server serves them at `/_vellum/katex/`; PDF output and standalone HTML link vellum's own copy under the user cache directory (`~/Library/Caches/vellum/katex/<version>/` on macOS), written on first use. The previous link was pinned to 0.16.21 while the renderer had moved to 0.16.45; the two now stay together, enforced by a test against the installed `katex` package (`scripts/vendor-katex.sh` refreshes the vendored copy after an upgrade).
- `convert.Options.KaTeXCSSHref` lets a sink that serves the assets itself name its own route; `convert.KaTeXAssetDir` exposes the cache-directory copy. Viewer pages cached by an earlier vellum re-render on first visit so they pick up the local link.
- PowerPoint output: slide text is matched across pandoc's per-token code runs.
- `pdffonts` (Poppler) joins the converters the gate requires.
