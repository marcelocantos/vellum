### Fixed

- **Inline SVG in a document is drawn again.** Since v0.43.0 the viewer removed every `<svg>` a Markdown document wrote, so inline drawings vanished. A drawing now stays real SVG in the page, with its text, links, styles, gradients, markers, `<use>`, animation and `foreignObject` labels. Only what can run is removed: script, event handlers, `javascript:` links, animation that rewrites a link, and form controls. Pages cached by an earlier version are drawn again.

### Notes

- An inline SVG's `<style>` applies to the whole page, as on any web page. Hand-written MathML is still removed; vellum renders `$…$` math itself.
