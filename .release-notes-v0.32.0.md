## Release verification

- **`make verify-release` checks an installed release end to end.** Run it after `brew upgrade vellum`. It uses only the Homebrew install. It checks `vellum --version`, restarts the `vellum-view-release` supervisord program and confirms it stays up for 60 seconds and reports the expected version over MCP. It then converts test fixtures: Markdown → PDF, HTML and PowerPoint, and DOCX → Markdown. It also confirms PDF conversion fails up front when WeasyPrint is missing, runs MCP `tools/list` and `convert` over HTTP, and checks the viewer page and its offline KaTeX assets. Any failure gives a non-zero exit and a pass/fail summary. `VERSION=` overrides the expected version, which defaults to the latest tag.
- **Dev and release viewers side by side.** The new `supervisor/vellum-view-release.ini` template runs the Homebrew `vellum serve-view` on 127.0.0.1:18744, next to the dev `vellum-view` on 18742. It keeps its own render cache.
- `scripts/release-publish.sh` runs `verify-release` after its brew upgrade. With `--skip-brew` it prints a reminder to run it.
- No changes to the CLI, MCP or library behaviour.
