### Added

- **Viewer homepage.** `http://127.0.0.1:<port>/` lists the documents you opened recently and the Markdown files in the folders they came from.
- **Section tracking.** The contents panel marks the section you are reading and keeps it in view.
- **Dark diagrams.** Mermaid diagrams follow the dark theme instead of staying white.
- **Signed macOS binary.** The macOS binary is signed with Canticode's Developer ID, so macOS privacy permissions granted to vellum carry over from one release to the next.

### Changed

- **Viewer layout.** One top bar holds the homepage link, the contents toggle, the file's name and the actions. Once the first heading scrolls away the bar shows the document's title, and clicking it returns to the top. The heading that used to stick below the toolbar is gone.
- **Reading column.** Prose is 16px in a 760px column. Wide tables still extend to the panel's width. Print and PDF output are unchanged.
- **Narrow windows.** The contents panel opens over the page and closes on a click outside, Escape or a link.
- **New mark.** The viewer has a new icon.
- **Documents cannot run code in the viewer.** A document's own HTML is cut to an allow-list (no scripts, frames or event handlers), and a Content-Security-Policy admits only the viewer's scripts.
- **The viewer serves only folders you opened a document in.** Every route also refuses a request whose Host is not loopback, and requests from other sites.
- **PDF and clipboard conversion in the viewer fetch nothing a document names.** The viewer inlines local images from the served folders and fetches remote images itself.
- **Mermaid diagrams cannot load images by path or URL.** `data:` images still draw. A Mermaid CLI the confinement does not recognise is refused, and its diagrams are left as their source.
- **RTF files are written through pandoc.**
- **MCP `convert` fails when a request field would be ignored**, instead of dropping it silently.

### Fixed

- Since v0.42.0 a block narrower than the reading column, such as a diagram, sat against the right edge. Diagrams are now centred.
- With several Mermaid diagrams on a page, one diagram's styles applied to the others and clipped their labels.
- A long line of code no longer widens the page on a narrow window.
